Why RackDroid

Not a toy. A real rack.

Every design choice starts with one question: would this work with a finger on a 6-inch screen? If the answer was no, we redesigned it — not just shrank it.

It's VCV Rack, not a clone

Same DSP engine, same 66 modules, same .vcv format — built on unmodified upstream v2.6.4 sources.

Built for touch

Not a shrunk-down desktop UI: drag cables with a finger, long-press a knob to type a value, pinch to zoom.

Low native latency

Oboe/AAudio, full-duplex — it plays in real time, not a toy that stutters.

Grows with you

Start with the 66 built-in modules, then add whole packages (Bogaudio, Valley, Befaco…) on the fly, without updating the app.

Even on older hardware

Supported from Android 10 up: it runs on phones and tablets that aren't brand new anymore.

Open source, for good

GPLv3, complete sources in the repository. No account, no paid license, no tracking.

Interface

A real screenshot. Not a mockup.

Sequencer, VCO, VCF, ADSR envelope and mixer — taken from a real device running the app, with the glass toolbar open above the rack.

Inside the rack

What it includes

Everything you need to build a sound from scratch, already in the base APK.

🎚️

Audio engine

Native, Oboe/AAudio, full-duplex, low latency.

🧩

66 modules

Core, Fundamental (39 modules), RackDroid Drums (14 original voices).

👆

Real touch

Cables and modules with a finger, pinch to zoom, long-press for values.

🪟

Glass toolbar

Menus, module palette, plugin manager, undo/redo, layout lock.

🧲

Module palette

Chips by category, draggable previews, an info badge for every module.

🧵

Cable parking

Park a cable end on a bar, scroll to the far module, drop it on the port. 3 to 10 holes.

🎹

MIDI

On-screen keyboard, USB and Bluetooth LE MIDI.

⏺️

Recording

Output to a WAV file, saved in Documents/RackDroid/.

🎓

Guided learning

A spotlight interface tour on first run, 30 step-by-step tutorials, plus a topic guide.

Additional modules

Extra packages, no app update needed

Install .rdmod files from the built-in module manager, or copy them into the Modules/ folder — they load right away.
